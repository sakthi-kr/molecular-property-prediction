# Changelog

## v0.7.0 — Portfolio source release

- Reproducible data acquisition and chemical structure audit with source SHA-256 provenance.
- Molecular descriptors, Morgan fingerprints and leakage-audited random/scaffold partitions.
- Four established baselines, validation-based model selection, similarity diagnostics and calibration intervals.
- One-time locked held-out evaluation, scientifically qualified results summary and local SMILES inference interface.
- Clean-checkout tests, GitHub Actions, public source/data hygiene checks, reproducibility guidance, and release notes.

This is the first public portfolio snapshot; earlier version numbers were local development iterations, not published releases.
